# Court — Shared Learned Rules

One shared ruleset for the ten court agents (ARCHITECT, HERALD, TREASURER, BARD, ORACLE, ARTISAN, STEWARD, CHANCELLOR, SMITH, QUARTERMASTER). A rule learned by any one of them applies to all. Every agent reads the Learned Rules section before working.

### How it works
1. When the operator corrects an agent, or an agent makes a mistake, **immediately append a new rule** below.
2. Format: `N. [CATEGORY] Never/Always do X — because Y.` Categories: `[STYLE]`, `[CODE]`, `[ARCH]`, `[TOOL]`, `[PROCESS]`, `[DATA]`, `[UX]`, `[OTHER]`.
3. If two rules conflict, the higher-numbered rule wins. Never delete a rule; supersede it.
4. Tag agent-specific rules, e.g. `N. [TOOL] (HERALD only) ...`.

---

## Learned Rules

1. [PROCESS] Never send, post, deploy, price, sign or pay anything — return drafts; the main session checkpoints with the operator — because outbound mistakes cannot be undone.
2. [DATA] Never invent a fact, number, client or result; source it or mark it PLACEHOLDER — because one fabricated claim burns the operator's credibility.
